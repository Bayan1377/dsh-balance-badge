# dsh-balance-badge

Баланс аккаунта DeepSeek, всегда видимый в подвале боковой панели — рядом с шестерёнкой
настроек, без захода в «Настройки → Аккаунт».

## Что показывает

- Сумму по каждому кошельку в формате карточки баланса: два знака после точки,
  разделители тысяч, суммы меньше цента — как `<0.01` (положительные обрезаются до
  центов, отрицательные округляются с минимумом 0.01 — те же правила, что в настройках).
- Подсказку при наведении: общий баланс и бонусный кредит, если он есть.
- В свёрнутой панели (режим рейки 56 px) бейдж не рендерится, чтобы не ломать раскладку.

## Откуда данные

Клиентская половина вызывает существующий RPC аккаунта — `ctx.remote.account.getBalance`
с теми же метаданными клиента, что и штатная карточка аккаунта (версия сборки из
`window.__DSH_BOOT__.release.version`, активная локаль, смещение часового пояса).
Чтение выполняется:

- при загрузке страницы;
- каждые 5 минут;
- при возврате к окну (`visibilitychange`);
- после переподключения (`connection/reset`).

Бейдж работает по принципу «мягкого отказа»: если аккаунт не авторизован, RPC недоступен
или вернул ошибку, ничего не рисуется (и в консоль уходит предупреждение `[balance-badge]`).

## Состав

| Путь | Назначение |
|---|---|
| `package.json` | Манифест: `dsh.client` с `platform: web` и зависимостью от `@deepseek-ai/dsh-client-ui-sidebar`. |
| `lib/index.js` | Хостовая половина: пустой `apply()`. |
| `lib/client.js` | Бандл `window.__ModuleLoader__.load({ id, factory })`: словари, хранилище баланса, регистрация в слоте `sidebar.footer.action`. |

## Установка

Нужны Node.js 20+ и `pnpm` (DSH ставит плагины через него):

```powershell
dsh plugin --profile desktop add @bayan1377/dsh-balance-badge
```

Пакет несёт собственный bundle-патч, поэтому профиль править не нужно. Обновление —
двумя шагами, `add` поверх установленного пакета DSH отклонит:

```powershell
dsh plugin --profile desktop remove @bayan1377/dsh-balance-badge
dsh plugin --profile desktop add @bayan1377/dsh-balance-badge
```

После установки перезагрузите окно интерфейса.

## Удаление

```powershell
dsh plugin --profile desktop remove @bayan1377/dsh-balance-badge
```

## Ограничения

- Значение обновляется опросом, а не потоком: после пополнения или расхода оно догонит
  не позже чем через 5 минут (или сразу при возврате к окну).
- Клик по бейджу ничего не открывает: слот `sidebar.footer.action` не предоставляет
  действие «открыть настройки», а подменять штатную кнопку настроек ради этого не стоит.
